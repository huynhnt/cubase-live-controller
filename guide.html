HƯỚNG DẪN SỬ DỤNG & KẾT NỐI CUBASE

Cubase Live Controller là ứng dụng tối ưu hóa dành cho hát livestream và thu âm online trên Cubase. Hỗ trợ điều khiển 2 chiều thời gian thực thông qua tín hiệu Web MIDI.

🌟 CÁC TÍNH NĂNG NỔI BẬT

🎚️ Đồng Bộ 2 Chiều Thời Gian Thực

Điều khiển Vol Nhạc, Vol Mic, Mute Nhạc/Mic/Vang độc lập. Trạng thái nút bấm tự động đồng bộ thời gian thực giữa Cubase và Web App.

🎤 Chế Độ Hát Live & Voice Đối Thoại

Chuyển đổi 1-click giữa Hát Live (đầy đủ vang/autotune) và Voice Đối thoại (tắt vang nhưng giữ 1 lượng vang siêu nhỏ tự nhiên).

🎼 Dò Tone Thông Minh (Smart Tone)

Tự động phân tích tên bài hát Karaoke trên Youtube hoặc tần số âm thanh để gửi thẳng Key & Scale (Major/Minor) sang Auto-Tune trên Cubase.

🎹 Bảng Phím Nốt Autotune Ngang

Gồm 12 phím nốt nhạc tròn (C -> B) và 2 giọng (Trưởng/Thứ) giúp thay đổi tông bài hát nhanh chóng ngay lập tức.

🎛️ Tùy Chỉnh Vang Chi Tiết (FX Panel)

5 thanh trượt chi tiết: Vang Dài, Vang Ngắn, Delay, Autotune, Flex. Tích hợp sẵn bộ Preset giọng Bolero, Pop, Remix...

🔊 Soundboard Âm Thanh Pha Trò

12 ô gán hiệu ứng âm thanh (tiếng cười, vỗ tay...) phát trực tiếp offline ra thiết bị đầu ra mong muốn.

🛠️ HƯỚNG DẪN CÀI ĐẶT & KẾT NỐI CUBASE

  1. Bước 1: Cài đặt cổng MIDI ảo loopMIDI
    Tải phần mềm miễn phí loopMIDI. Mở phần mềm và nhấn nút + để tạo cổng MIDI ảo tên là: loopMIDI Port
  2. Bước 2: Nạp XML cấu hình Generic Remote vào Cubase
    Trong Cubase: Mở Studio -> Studio Setup (hoặc Devices Setup) -> Nhấn nút + chọn Generic Remote.
    - MIDI Input: Chọn loopMIDI Port
    - MIDI Output: Chọn loopMIDI Port
    - Nhấn nút Import và chọn file Cubase_Live_Controller_Generic_Remote.xml đi kèm. Bấm Apply -> OK.
  3. Bước 3: Đặt tên Track trong Cubase
    Để lệnh MIDI ánh xạ chính xác:
    - Đổi tên track chứa Nhạc nền thành: Beat
    - Đổi tên track chứa Micro thành: Mic
    - Đặt plugin Auto-Tune Pro (phiên bản có MIDI) ở ô Insert 1 trên track Mic.

⚙️ DANH SÁCH BẢNG ÁNH XẠ MIDI CC MẶC ĐỊNH

Các cổng CC này có thể linh hoạt thay đổi trong mục Cài đặt ⚙️ của ứng dụng:

Chức năng Cổng CC Giá trị tín hiệu
Âm lượng Nhạc (Beat Volume) CC 20 0 (Mute) - 127 (Max)
Bật/Tắt Nhạc (Beat Mute) CC 21 >=64 (Tắt) / <64 (Mở)
Âm lượng Mic (Mic Volume) CC 22 0 - 127
Bật/Tắt Mic (Mic Mute) CC 23 >=64 (Tắt) / <64 (Mở)
Bật/Tắt AutoTune (FX Mute) CC 24 >=64 (Tắt) / <64 (Mở)
Vang Dài (Reverb Long) CC 25 0 - 127
Vang Ngắn (Reverb Short) CC 26 0 - 127
Delay CC 27 0 - 127
Auto-tune CC 28 0 - 127
Flex CC 29 0 - 127
Chế độ Hát / Voice CC 30 127 (Hát Live) / 0 (Voice Đối thoại)
Tông Autotune (Key) CC 31 Chia đều 0 - 127 cho 12 nốt nhạc
Điệu Autotune (Scale) CC 32 0 (Trưởng / Major) / 127 (Thứ / Minor)
